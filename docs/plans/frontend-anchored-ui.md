# Climber 前端锚定式 UI 规范

本文件是用户 2026-10-02 明确要求固化到记忆中的前端执行规范。Climber 前端任何布局、组件摆放、显隐逻辑、视觉样式修改都必须先按本规范执行，禁止自由发挥布局。

## 当前决策优先级（2026-10-02 更新）

用户通过选择式确认将 Codex 桌面工作台设为整体布局与操作流程的优先参考。下文原三栏固定布局作为既有实现基线；与有公开证据的 Codex 桌面布局冲突时，以本节最新决策为准，逐项更新实施与验收标准。

- 参考依据使用官方公开文档、产品图及公开源码；标明版本、来源与实际可验证范围。
- 模型和思考等级在输入区直接显示，权限和技能等通过紧凑菜单操作。
- 运行中提供“补充当前任务”和“排队下一任务”两个明确动作，分别对应下一安全步骤生效与当前任务结束后执行；后端确认前显示待确认状态。
- 默认展示简明进度，参数、日志、子任务与公开推理摘要通过详情展开。
- 默认面板组织方式依据 Codex 桌面官方参考证据确定；尚未取得证据的细节标为待核实。
- Climber 品牌图标、用户本地画像与自有能力保留，公开参考来源的品牌资产保持独立。

## 一、三家前端核心优点融入清单

### OpenAI Codex
- 底部输入栈弹窗机制：不跳转页面、不打断流程。落在中间栏底部输入区上方。
- 状态内嵌式指示器：实时反馈 Agent 内部状态。落在中间栏底部状态栏。
- 任务阶段驱动面板自动显隐：不用手动切面板。落在全局面板显隐逻辑。
- 工具调用卡片内嵌展开：结果不占满屏，上下文不中断。落在中间栏消息流。
- 模式切换对应 UI 精简度。落在全局配置档。

### DeepSeek Hermes
- 左栏技能 + 配置双管理：分类清晰，一键开关。落在左侧导航栏中下区。
- 右栏子 Agent 任务树 + 缓存仪表盘：执行过程全可视化。落在右侧信息面板中上区。
- 斜杠命令系统：输入框直接触发功能。落在中间栏底部输入框。
- 记忆 / 规则可视化编辑：不改代码直接改配置。落在右侧信息面板 + 弹窗。
- 三栏标准开发者工作流布局：左管理 - 中交互 - 右信息。落在整体布局骨架。

### Workbay
- 设计令牌系统 + AI 可读规范：AI 生成 UI 100% 符合规范。落在全局视觉体系。
- 项目上下文总线：所有资产共享，不用重复说明。落在全局数据层。
- 资产版本化管理：组件、规则统一管控。落在组件库 + 配置系统。
- 多模式递进权限：信任度逐步提升，功能逐步放开。落在配置档分级。
- 生成式 UI 组件协议：AI 通过指令控制界面，不破坏架构。落在 UI 渲染底层规则。

## 二、锚定式三栏布局

### 总布局尺寸规则（强制，不可修改）

页面总层级从下到上：页面背景 → 三栏面板容器 → 业务组件 → 弹窗层 → 全局提示条。

- 左侧导航栏：默认宽 240px，最小 180px，最大 360px，折叠后宽 60px。
- 中间主交互区：自适应填充剩余宽度，最小 600px。
- 右侧信息面板：默认宽 320px，最小 240px，最大 480px，可完全折叠。
- 所有面板分割线 1px，支持拖拽调宽，拖拽时显示半透明指示线。

### 左侧导航栏（从上到下顺序、功能、高度固定）

1. 顶部 Logo 区（高 48px，固定不可折叠）
   - 左侧：产品图标 + 产品名称。
   - 右侧：全局设置按钮。
   - 规则：点击 Logo 返回默认会话，禁止添加其他功能。
2. 会话管理区（可折叠，默认展开）
   - 顶部：分区标题 + 新建会话按钮（居右）。
   - 列表项：每条高 40px，从左到右 = 会话图标 + 会话标题 + 最新消息时间（居右）。
   - 交互：当前会话高亮主色背景，悬停浅灰背景，右键菜单 = 重命名 / 删除 / 置顶。
3. 技能中心区（可折叠，默认展开）
   - 顶部：分区标题 + 搜索框（居右）。
   - 分类：按功能分组折叠，分类标题带展开箭头。
   - 技能项：每条高 36px，从左到右 = 技能图标 + 技能名称 + 启用开关（居右）。
   - 规则：已启用技能名称高亮主色，点击开关即时生效。
4. 配置档管理区（可折叠，默认折叠）
   - 顶部：分区标题。
   - 配置项：每条高 36px，从左到右 = 配置图标 + 配置名称 + 当前使用标记（居右）。
   - 规则：点击切换全局生效，对应不同 UI 复杂度、工具权限、提示词策略。
5. 底部用户区（高 48px，固定在栏底）
   - 左侧：用户头像。
   - 中间：用户名。
   - 右侧：退出按钮。

### 中间主交互区（从上到下顺序固定）

1. 顶部会话标题栏（高 48px，固定）
   - 左侧：会话标题 + 当前状态标签。
   - 右侧：视图切换按钮（聊天视图 / 任务视图）+ 更多操作按钮。
   - 规则：状态标签实时同步 Agent 状态，禁止添加其他无关按钮。
2. 中部消息流展示区（自适应高度，核心区）
   - 内边距：上下大间距，消息之间中间距。
   - 对齐规则：用户消息靠右，Agent 消息靠左。
   - 五种消息类型，顺序、样式不可混用：
     1. 用户输入气泡：主色浅淡背景。
     2. Agent 思考气泡：面板背景，左侧带思考图标 + 动效。
     3. 工具调用卡片：边框式，顶部工具名 + 状态标签，中部入参摘要，底部展开按钮。
     4. 工具结果块：默认折叠，仅显示状态标签 + 展开按钮；展开后显示完整日志，最大高 240px。
     5. 代码差异块：左右分栏，左删除红底，右新增绿底，行号对齐。
   - 时间戳：每条消息下方居中，小字辅助色。
3. 底部输入栈区（最小高 64px，最大高 240px）
   - 内部从左到右：附件按钮 + 技能选择按钮 → 多行输入框 → 发送按钮。
   - 输入框占位符：提示支持斜杠快捷指令。
   - 弹窗栈机制：
     - 所有临时交互（工具审批、参数配置、输入确认）都在输入区上方堆叠弹出，宽度和输入区一致。
     - 按触发顺序堆叠，最新的在最上层。
     - 完成 / 取消后自动销毁，不残留页面，不跳转界面。
   - 底部状态栏（高 24px）：从左到右 = Agent 状态图标 + 文案 → 缓存命中率 → 本轮 Token 消耗。
   - 状态四种：思考中 / 执行工具 / 等待输入 / 异常，每种固定颜色和动效。
   - 全部小字辅助色，禁止放大或高亮。

### 右侧信息面板（从上到下卡片顺序固定）

1. 任务看板卡片（默认展开）
   - 头部：标题 + 新建任务按钮（居右）。
   - 三泳道布局：待执行 → 执行中 → 已完成。
   - 任务卡片：高 64px，顶部任务名，底部状态标签 + 时间。
   - 规则：阻塞任务红色边框 + 底部阻塞原因小字；支持拖拽切换泳道。
2. Token 计量仪表盘卡片（默认展开）
   - 头部：标题 + 重置按钮（居右）。
   - 指标区：两行三列，显示累计输入 Token、累计输出 Token、缓存命中率、预估总费用、今日消耗、平均单轮消耗。
   - 趋势区：柱状图展示最近 10 轮消耗，不同颜色区分输入、输出、缓存节省。
3. 子 Agent 任务树卡片（默认折叠）
   - 头部：标题 + 全部展开 / 折叠按钮（居右）。
   - 树结构：层级缩进，每个节点从左到右 = 状态图标 + 任务名称 + 耗时（居右）。
   - 规则：失败节点红色高亮；点击节点展开查看子任务详情。
4. 文件预览卡片（默认折叠）
   - 头部：文件名 + 关闭按钮，多文件标签页横向排列。
   - 内容区：代码 / 文本预览，新增行左侧绿标，删除行左侧红标，修改行左侧黄标。
   - 底部：文件路径小字。
5. 规则编辑器卡片（默认折叠）
   - 头部：标题 + 保存按钮（居右）。
   - 内容区：可视化编辑 SOUL 规则、记忆条目、项目规范。
   - 规则：保存即时生效，同步到项目上下文总线。

## 三、AI 驱动 UI 精准触发规则表

| 触发条件 | 执行动作 | 目标组件 | 对应优点 |
| ---- | ---- | ---- | ---- |
| 用户发起新任务，进入规划阶段 | 自动展开 | 右侧任务看板卡片 | Codex 任务驱动面板 |
| Agent 开始调用工具 | 插入工具调用卡片、更新状态栏为「执行工具」 | 中间消息流、底部状态栏 | Codex 状态实时反馈 |
| 工具执行完成 | 更新工具卡片状态、失败则自动展开工具结果 | 中间消息流 | Codex 内嵌式结果 |
| Agent 拆分出子任务 | 自动展开子 Agent 任务树、新增任务节点 | 右侧子 Agent 任务树卡片 | Hermes 任务可视化 |
| Agent 编辑代码 / 文件 | 自动展开文件预览卡片、高亮变更部分 | 右侧文件预览卡片 | Codex 上下文同步 |
| 任务执行结束 5 秒后 | 自动折叠 | 任务看板、子 Agent 任务树、文件预览 | Codex 自动精简界面 |
| 触发工具需要用户审批 | 从输入区上方弹出审批弹窗 | 底部弹窗栈 | Codex 不打断流程 |
| 用户输入斜杠命令 | 匹配对应功能，直接执行 | 底部输入框 | Hermes 快捷指令 |
| 切换配置档 | 同步调整 UI 显示复杂度、工具权限、面板数量 | 全局界面 | Workbay 多模式递进 |
| 出现错误 / 异常 | 状态栏变红、弹出错误提示 + 原因 + 重试按钮 | 底部状态栏 + 全局提示 | 三家通用错误友好 |

## 四、AI 生成防乱写强制校验清单

1. 位置校验
   - 三栏顺序必须是左导航 - 中聊天 - 右信息，禁止调换。
   - 左栏、中栏、右栏内部组件顺序必须与上文一致，禁止上下调换。
   - 弹窗必须从对应位置弹出，禁止居中乱跳。
2. 功能校验
   - 三家所有对应优点必须全部出现，禁止遗漏。
   - 每个组件功能必须与定义一致，禁止私自添加功能。
   - 面板显隐必须按触发规则执行，禁止默认全部展开。
3. 视觉校验
   - 所有颜色、间距、圆角、字号必须调用设计令牌变量，禁止硬编码数值。
   - 禁止添加任何未定义的装饰性元素、渐变、动画。
   - 五种消息气泡样式必须严格区分，禁止混用。
4. 交互校验
   - 所有可交互元素必须有默认、悬停、选中、禁用四种状态。
   - 所有操作必须有明确反馈，错误必须显示原因 + 重试按钮。
   - 面板拖拽必须有最小 / 最大宽度限制，禁止拖出边界。
